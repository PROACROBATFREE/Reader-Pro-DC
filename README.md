# Reader Pro DC

**Reader Pro DC** edits PDFs on the machine. Windows 11 and 10. Text, Word export, merge, compress, sign, OCR. Portable 64-bit. No Creative Cloud plan.

<img width="256" height="256" alt="images1" src="https://github.com/user-attachments/assets/d35d9b1f-7fdc-4ea7-bc90-d4f4386d207a" />

Unpack, run. After install, set this build as the default app for `.pdf` if Edge still owns the association.

## FAQ

**Portable?**
Yes. Same zip, portable folder inside.


**Creative Cloud?**
Not required for the local editor path.

**Empty Word export?**
Scan with no text layer. Run OCR first.
